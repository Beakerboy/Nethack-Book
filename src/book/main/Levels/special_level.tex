\part{Special Level}
A \textbf{special level} has some unusual features that differ from the normal dungeon-{}, mine-{}, or maze-{}style levels. Usually some parts of these levels are not randomly generated. The special levels are made with a special programming language, which are then compiled into .lev -{}files by lev\_com. NetHack loads the .lev-{}file when needed and creates the special level based on the instructions in it.
